## 🎨 Animation Flow

### Logo Sequence

```
1. Mouse Enter
   ↓
2. Start 360° rotation
   ↓
3. Split into letters
   ↓
4. Each letter bounces up
   ↓
5. Double glow appears
   ↓
6. Scale to 1.2x
   ↓
7. Mouse Leave
   ↓
8. Smooth return to normal
```

### Nav Link Sequence

```
1. Mouse Enter
   ↓
2. Lift up 8px
   ↓
3. Apply 3D tilt (10°)
   ↓
4. Background glow fades in
   ↓
5. Underline slides in (elastic)
   ↓
6. Color changes to primary
   ↓
7. Mouse Leave
   ↓
8. Smooth return (unless active)
```

### Button Sequence

```
1. Mouse Enter
   ↓
2. Scale up
   ↓
3. Rotation/Shine effect
   ↓
4. Glow appears
   ↓
5. Additional effects (arrow, etc.)
   ↓
6. Mouse Leave
   ↓
7. Smooth return to normal
```
