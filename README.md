# React Portfolio - Modern & Interactive

A fully functional, modern portfolio website built with React, Vite, and Tailwind CSS.

## ✨ Features

- 🎨 **Dark/Light Mode Toggle** - Switch between themes
- 📱 **Fully Responsive** - Works on all devices
- 🎯 **Smooth Scrolling** - Navigate sections smoothly
- 🔍 **Project Filtering** - Filter projects by category
- ✉️ **Contact Form** - With validation
- 🚀 **Fast Performance** - Built with Vite
- 💫 **Animations** - Smooth transitions and effects
- 📊 **Active Section Tracking** - Highlights current section

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📦 Technologies

- React 18
- Vite 6
- Tailwind CSS 3
- Custom Hooks
- Intersection Observer API

## 🎨 Customization

Edit the content in the component files:

- `src/components/Header.jsx` - Hero section
- `src/components/About.jsx` - About section
- `src/components/Projects.jsx` - Projects
- `src/components/Skills.jsx` - Skills
- `src/components/Contact.jsx` - Contact form

## 🌐 Deployment

Ready to deploy to Vercel, Netlify, or GitHub Pages.
